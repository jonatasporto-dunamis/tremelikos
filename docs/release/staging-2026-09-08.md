## 4. Estratégia de Backup/Rollback

**Baseado em `docs/RUNBOOK.md` (seção 1.1):**

- **Supabase**: dump automático diário, retenção 7 dias (Free) / 30 dias (Pro).
- **Backup extra local** (cron 04:00 BRT):
  ```bash
  pg_dump "postgresql://postgres:[PASSWORD]@${DB_HOST}:5432/postgres" \
    --no-owner --no-privileges -Fc \
    -f /var/backups/supabase/tremelikos-$(date +%Y%m%d).dump
  ```
- **Rollback de migrations**: Supabase suporta rollback de migrations via `supabase db reset` (para dev) ou restore de backup.
- **Rollback de migration 010 (RLS scoping)**: A política de escopo por loja pode ser revertida restaurando policies antigas de migration 004/007, procedimento documentado no RUNBOOK.
